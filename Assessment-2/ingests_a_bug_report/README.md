# Bug Resolution Agents

This repository implements an automated multi-agent system that analyzes a bug report, parses logs, generates a reproducing script, executes it (as a tool), and finally creates a root-cause hypothesis and patch plan.

## Setup

1. Make sure you have python installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your OpenAI API Key:
   Create a `.env` file in the root directory `c:\Users\asus\Vision\bug_resolution_agents`:
   ```env
   OPENAI_API_KEY=your_openai_api_key_here
   ```

## How It Works (Based on Assessment criteria)

- **Option A (Mini-Repo)**: A simulated small codebase `mini_repo/` is provided, featuring `app.py` with an intentional bug (ZeroDivisionError with 100% discount calculations).
- **Multi-Agent Orchestration**: The system uses Python to orchestrate several logical LLM agents (`Triage`, `Log Analyst`, `Reproduction`, `Fix Planner`, `Reviewer`), separating responsibilities explicitly with a deterministic workflow.
- **Tool Usage**: Standard python `subprocess` is used programmatically by the orchestrator to execute the code generated by the `Reproduction Agent`, which represents tool usage/tool execution for capturing standard output/errors in an isolated way.
- **Structured Outputs**: The final output is written deterministically to `resolution_output.json`.

## Deliverables Generated
Upon running `python main.py`, it generates:
- `repro.py`: The isolated runnable script reproducing the failure (Runnable Artifact).
- `resolution_output.json`: The fully detailed structured output mapping hypotheses to evidence.
